# Integration guide

Written for merchants integrating the gateway. Filled in as features ship; the 10-minute quick start lands with M3
(invoices + hosted checkout) and webhook verification with M6.

2. Test mode walkthrough (BSC testnet, mock USDT faucet)
3. Webhook verification (Node, PHP, Python, Go)
4. Payment links (no-code)
5. Embeddable widget (`gateway.js`)
6. Non-custodial setup (exporting an account xpub, scanning addresses)
7. Go-live checklist for merchants
